# Portfolio de Sara María Marí Perdices

Paquete estático preparado para el repositorio `sarammari/portfolio` de GitHub Pages.

El archivo `CNAME` conserva la conexión existente con `saramariamariperdices.com` y no debe eliminarse.

## Publicación

1. Crear un repositorio público en GitHub.
2. Subir el contenido de esta carpeta a la rama `main`.
3. En **Settings → Pages**, elegir **Deploy from a branch**, `main` y `/ (root)`.
4. Comprobar la dirección provisional antes de conectar el dominio propio.

## Contenido

- `index.html`: statement, proyectos y contacto.
- Cinco páginas de proyecto: Momias, Niña con coletas, Intro al collage, Trapos sucios y Ramas.
- `css/style.css`: maquetación completa y adaptación móvil.
- `js/script.js`: navegación de la portada y selector de idioma ES/CA/EN.
- `assets/images/`: únicamente las imágenes actualmente utilizadas por la web.

La relación de imágenes derivadas o editadas está documentada en `ASSET_NOTES.md`.
